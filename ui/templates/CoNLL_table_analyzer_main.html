Input & output

The script expects a single CoNLL csv file or a directory containing a set of csv files.

All output files (txt, csv, png, html) are saved here; most tools organize results into their own subdirectories inside it.

Analyses

Analyzes the CoNLL table for clause types (e.g., noun-phrase NP, verb phrase VP), nouns (singular, plural, proper, subject and object), verbs (modality, tense, voice), function words (articles/determinants, auxiliaries, conjunctions, prepositions, pronouns), adjectives, adverbs, and ratios of word classes (e.g., content vs. junk words).

Computes counts and proportions of nouns, verbs, adjectives, and proper nouns across the selected K beginning and ending sentences.

Computes a sentence table with various sentence statistics.

Token search

Searches the CoNLL table for a specific case-sensitive token (one word only; * for any word). In output, the algorithm produces several charts and a Gephi network graph of the relationship between searched and co-occurring words.

More about token search

The EXACT word will be searched (e.g., if you enter 'American', any instances of 'America' will not be found). DO NOT USE QUOTES WHEN ENTERING A SEARCH TOKEN.

The algorithm will search all the tokens related to this token in the CoNLL table. For example, if the token wife is entered, the algorithm will search in each dependency tree (i.e., each sentence).

FORM matches the exact token (brother only); LEMMA also matches inflected forms (brother and brothers).

POSTAG value for the searched token (e.g., NN for noun; * for any). DEPREL value for the searched token (e.g., nsubjpass for passive nouns that are subjects; * for any).

POSTAG and DEPREL values for tokens co-occurring in the same sentence (* for any).
