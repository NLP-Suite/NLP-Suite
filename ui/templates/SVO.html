Coreference resolution

Resolves pronouns to the nouns they refer to before extracting SVOs. Be patient: depending on the size and number of documents, this may take a long time.

More about coreference resolution

Only pronominal, and not nominal, coreference resolution is implemented, for four different types of pronouns: nominative (I, you, he/she, it, we, they); possessive (my, mine, our(s), his/her(s), their, its, yours); objective (me, you, him, her, it, them); reflexive (myself, yourself, himself, herself, oneself, itself, ourselves, yourselves, themselves).

In INPUT the algorithm expects a single txt file or a directory of txt files. In OUTPUT it produces txt-format copies of the same input files, co-referenced.

Fix missed or wrongly coreferenced pronouns by hand. Requires the interactive split-screen editor not yet ported from the desktop app.

More about manual editing

If manual edit is selected, the script displays a split-screen file for manual editing. On the left-hand side, pronouns cross-referenced by CoreNLP are tagged in YELLOW; pronouns NOT cross-referenced by CoreNLP are tagged in BLUE. On the right-hand side, pronouns cross-referenced by CoreNLP are tagged in RED, with the pronouns replaced by the referenced nouns.

Manual editing requires a lot of memory since both original and co-referenced file are brought in memory; depending on file sizes, you may not have enough memory for this step. You can always use the 'coreference_main' GUI to open or split merged coreferenced files.

Extraction

NLP package used to extract SVO triplets from your corpus.

Annotate the gender (female, male) and/or the speaker involved in direct discourse for every extracted Subject and Object. Both neural network annotators are available only via Stanford CoreNLP and for the English language only.

Lemmatize & filter

Lemmatizing aggregates words into WordNet top synset categories (e.g., 'run' into 'motion'). Filtering keeps only SVO triplets that match dictionary filter files; when S, V, and O filters are all selected, all conditions must be met. WordNet-based filtering is available for the English language only.

More about filter files

The widgets below display the currently selected dictionary filter files for Subjects, Verbs, and Objects (Objects share the same file as Subjects and you may wish to change that). The file 'social-actor-list.csv', created via WordNet with the multiple keywords act, group, person and saved in the 'lib/wordLists' subfolder, is automatically set as the DEFAULT filter for subjects; the file 'social-action-list.csv' is similarly created via WordNet (keywords: change, cognition, communication, contact, emotion, motion, social) and automatically loaded as the DEFAULT dictionary file for verbs.

The file widgets are disabled because you are not allowed to tamper with these values.
