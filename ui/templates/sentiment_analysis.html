Analysis options

Neural network approaches typically achieve better results than dictionary-based approaches.

More about the algorithms

BERT, spaCy, Stanford CoreNLP, and Stanza compute mean values only for each sentence on a scale 0-4 (minimum-maximum).

ANEW (Affective Norms for English Words) computes sentiment/arousal/dominance mean/median values for each sentence using the ANEW ratings for SENTIMENT (VALENCE), AROUSAL, and DOMINANCE (CONTROL) by Bradley, M.M. & Lang, P.J. (2017). Affective Norms for English Words (ANEW): Instruction manual and affective ratings. Technical Report C-3. Gainesville, FL: UF Center for the Study of Emotion and Attention. Contrary to all other approaches, ANEW computes three different measures: SENTIMENT or VALENCE measures how pleasant/unpleasant a word makes us feel; AROUSAL measures how calm/excited a word makes us feel; DOMINANCE or CONTROL measures how dominated/in control a word makes us feel. Values are classified on a scale 0-9, grouped in 5 categories: <3, >=3 and <5, 5 (neutral), >5 and <8, >=8 and <=9.

The Hedonometer algorithm uses the hedonometer.org rated dictionary to compute sentiment mean/median values for each sentence. It works best with social media texts (e.g., Twitter), New York Times editorials, movie reviews, and product reviews. Sentiment values are classified on a scale 0-10, grouped in 3 categories: negative (>=0 and <4), neutral (>=4 and <=6), and positive (>6 and <=10).

The NLTK VADER (Valence Aware Dictionary and sEntiment Reasoner) uses the NLTK rated dictionary to compute 'compound' sentiment values for each sentence (mean and median are not available). It works best with social media texts. Values are classified on a scale -1 (most negative) to 1 (most positive), grouped in 3 categories: negative (<-0.05), neutral (>=-0.05 and <=0.05), and positive (>0.05 and <=1). VADER relies on several NLTK libraries; if it fails to run, run python -m nltk.downloader all in a command line.

By default both values are computed.

More about mean & median

BERT, spaCy, Stanford CoreNLP, and Stanza Sentiment Analysis algorithms only compute mean values for each sentence, rather than each word.

VADER only computes 'compound' values for each sentence. SentiWordNet as well does not provide sentence mean/median values.

Visualization

Displays a line plot of sentiment scores by sentence index across a specific document.

Computes and visualizes the 'shape of stories' of sentiment scores across documents using Hierarchical Clustering, Singular Value Decomposition, or Non-Negative Matrix Factorization. Only available when computing sentiment via BERT, spaCy, Stanford CoreNLP, or Stanza on a corpus of txt files.
