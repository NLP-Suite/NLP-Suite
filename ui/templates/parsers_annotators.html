Input & output

The script expects a single txt file or a directory containing a set of txt files.

The algorithms produce different file types here: txt-format coreferenced copies of input files, csv files (HTML for gender annotator), and different types of visuals.

Parsers

Produces a CoNLL table (CoNLL U format) — the basis of many NLP analyses: noun & verb analysis, function words, clause analysis, query CoNLL.

PCFG is the recommended default; the neural network parser is more accurate but much slower.

Opens the CoNLL table analyzer to analyze the Stanford CoreNLP parser results contained in the CoNLL table.

Annotators

Click the Tips File for more information on the different annotators.

Resolve unresolved or wrongly resolved coreferences by hand. Manual editing requires a lot of memory since both original and co-referenced file are brought in memory.

The CoreNLP Quote annotator attributes quotes to speakers; double quotes is the default. Tick to process both double and single quotes.
