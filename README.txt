NLP Suite

To use the NLP Suite, download the zip for your computer (Windows, or Mac with Apple Silicon) from https://github.com/NLP-Suite/NLP-Suite/releases, unzip it, and follow GETTING_STARTED.txt inside the folder. No Python, Anaconda or Java installation is needed.

For more information, see README.md and the Wiki at https://github.com/NLP-Suite/NLP-Suite/wiki

To run from source code (developers), see the "Developer Setup" section of https://github.com/NLP-Suite/NLP-Suite/wiki/Install-the-NLP-Suite
