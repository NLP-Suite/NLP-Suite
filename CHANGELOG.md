# NLP Suite — Changelog

The most recent release is at the top. Each release's bullets are shown as **"What's new"**
on the corresponding GitHub Release page (the top section is added automatically by the
release workflow). Keep the newest version's section at the very top and update it before tagging.

## v1.6.35
- **Character emotion arcs — the comparison charts were unreadable, and three separate faults were why.** Every character was drawn from the left edge against *their own* number of sentences, so whoever appears most ran furthest and seemed to take over the story; the charts now share **one narrative axis** for the whole corpus (documents in order), with a second chart that still compares the *shapes* of arcs belonging to characters who appear very different amounts. Character names are merged **across the whole corpus** and matched on whole words, so one person is no longer split into "Harry", "Harry's", "Harry Potter" and "Harrys" — on the Harry Potter corpus that is 1,822 "characters" down to 1,332, and the leading character's sentence count up from 14,522 to 16,641. And thousands of sentences are now averaged into readable stretches, with a stretch holding fewer than three of a character's sentences left blank rather than drawn as a spike.
- **Corpus Profiler now reports the number of SENTENCES**, in the header and in the summary's abstract. It comes from your configured parser's own tables (CoreNLP and Stanza split sentences differently and do not agree), and says *"(estimated)"* when no parse is available rather than quietly counting full stops — which reads every "Mr." as the end of a sentence.
- **The Profiler's summary now says how much to trust the emotion arcs**, not only what is in them: the largest emotional swing across the corpus, the typical swing, and a verdict of *flat / modest / pronounced*. A corpus whose arcs are only noise now says so.
- **GIS: character-movement outputs were being destroyed by the run that produced them.** With "MAP characters moving in time and geocodable space" ticked together with any other GIS option, the movement files were written, deleted a moment later, and then handed to Excel — which is where the *"Sorry, we couldn't find …"* message came from. That map now also plays in narrative order and offers a document filter, as the Profiler's version always did.
- **Your input folder is no longer analysed as if it held an extra document.** A one-byte bookkeeping file written by the PC-ACE tool ended in `.txt`, so a corpus of five articles was being read as six. It is no longer written as a text file, and corpus listings skip such files.
- **Symbolic (non-geocodable) space — the pipeline works end to end.** The two map/distribution steps said their input was *"a file you assemble yourself — no single tool outputs it"*, three lines below the help for the step that produces exactly that file. Now: run **BUILD**, and its output is handed to the next steps with the Location and Sequence columns already selected.
- **Symbolic space: the social attribute is worked out for you.** The distribution analysis needs to know *what kind of person* each actor is, and you were told to code it by hand. A new social-actor typology classifies them — sheriff → military_police, mob → crowd_collective, sharecropper → laborer — from an editable list plus WordNet, the same method already used for places. Proper names are never guessed at.
- **Symbolic space: pronouns are no longer counted as characters.** "He", "they" and "which" were being recorded as actors, where they become the largest "actors" in every table while naming nobody. They are left out, and you are told how many events that cost and how coreference resolution brings them back.
- **New: an interactive view of movement through symbolic space.** A timeline you can play or drag — narrative position across, kind of space up the side, one track per character — showing *when* each character is in each kind of space, and where two characters are in the same kind of space at the same point in the story. Click any point to read its sentence.
- **Symbolic-space movement was mixing up documents.** Rows were ordered by sentence number alone, and sentence numbers restart in every document, so a 199-document corpus was read as one interleaved narrative. Movements are now counted within each document.
- **Three TIPS files.** New: **"Character emotion arcs"** and **"Characters moving in time and space"**. Rewritten: **"Narrative non-geocodable symbolic space"**, which now lists every space type and every social-actor type with examples — it previously named eight of the ten space types in passing and left the rest undocumented.

## v1.6.34
- **New: pdf → docx converter (keeps the pictures).** Converting a pdf to txt has always thrown away every image embedded in it. The new **"Document converter (pdf --> docx)"** option keeps **both the text and the images** in a single Word document, along with the bold, italics, type size and colour of the original, and joins the pdf's line breaks back into flowing sentences. Note it is a *reflow*, not a photographic copy: single column, no original page layout, and tables come through as lines of text.
- **New: OCR for scanned pdfs.** The **"Document converter (pdf --> txt) (SCANNED pdf, via pytesseract OCR)"** option reads the text out of pdfs that are just a picture of each page — scans, photocopies, historical documents. It needs software we cannot bundle (Tesseract and poppler); the tool checks for all of it and tells you exactly what to install and how. Several languages can be read in one pass, taken from your **Corpus language** setting. *(The old "via pytesseract" menu entry never actually did OCR — it silently ran the ordinary pdf converter.)*
- **File Classifier now works without hand-editing a config file.** The tool needs a *second* input directory, and its RUN button stayed greyed out until you typed that directory into `NLP_default_IO_config.csv` by hand — selecting it in the GUI did nothing, and the Setup I/O window it offered you didn't even show the field. All three problems are fixed: the field appears where it should, selecting a directory enables RUN, and a directory already in your config file now shows up in the GUI.
- **pdf → txt conversion fixes.** Converted files could be written **outside** the output folder you chose when a sibling folder had a similar name; one unreadable pdf aborted an entire batch (it now finishes and lists what failed); `.PDF` files in capitals were silently skipped; and converting a long book was needlessly slow.
- **New TIPS file, "pdf converters (including OCR)".** Six pages covering which converter to use (starting from the one question that decides it — can you select the text in your pdf?), full Windows and Mac installation instructions for OCR, language packs, and — for tabular material — how to extract pdf **tables** into csv files yourself.

## v1.6.33
- **Mac launch fixed and simplified.** The Mac download now has a **single** launcher — double-click **"Launch NLP Suite (Mac).command"** to start the suite (it clears macOS's download quarantine for you the first time). The redundant **"NLP Suite Mac Setup"** app has been removed from the Mac zip. If you previously got an error like *"code signature … not valid"* or *"library load disallowed by system policy"* when opening the `NLP_Suite` file directly, use the `.command` launcher instead — that error is exactly what it fixes. The download page and getting-started guide have been updated to say so.

## v1.6.4
- **SVO extraction — many fixes.** The **gender** and **quote/speaker** annotators now work (they were crashing while writing their output files), and gender values populate correctly. Running SVO **with coreference resolution** no longer errors. The social-actor **Filter** actually filters (it was a no-op in some paths). An internal processing tag no longer leaks into charts and wordclouds. The **character-movement map** now displays your locations (it was opening blank), can be restricted to social actors, and labels what the moving items are.
- **Quote/dialogue annotator rewritten.** One row **per quote** — it no longer drops extra quotes in the same sentence or duplicates a quote that spans several sentences — and speakers are resolved to the actual name where possible instead of a bare pronoun.
- **Annotators run without a Setup detour.** Ticking a CoreNLP-only annotator (gender, quote, normalized NER date, OpenIE) now runs it via Stanford CoreNLP automatically, whatever your default package.
- **CoNLL Table Analyzer — repetition finder.** The **Begin K / End K** sentence-count fields now appear only when the repetition-finder analysis is selected (with a hover explaining them).
- **"By Document" charts fixed.** Multi-value distributions charted *by Document* (e.g., NER date types) now produce a proper **grouped bar chart** — one colored series per document, clean document names in the legend, a "Frequencies" y-axis — or field totals when there are too many documents/values to chart legibly. This removes the long-standing empty/duplicate series whose values only showed up in the data sheet. *(Good area to spot-check: the Normalized NER date annotator and any "… by Document" analyses.)*
- **Wordclouds:** multi-word expressions (e.g., proper names) now read as clean joined units instead of running together.

## v1.6.3
- **Faster corpus & sentence statistics charts.** The tools that build per-sentence charts (sentence complexity, subordination) no longer re-run the language model on every document just to count its sentences — a large speed-up on multi-document corpora, with identical results.
- **Fixed a crash in "What's in your corpus → sentence complexity".** It was trying to reinstall an old version of a language library at run time and failing; it now downloads the needed model instead.
- **Chart engine modernization (behind the scenes).** ~100 chart-producing tools were moved onto a cleaner internal chart interface. Charts look and behave exactly the same, but the code is far simpler and several long-standing chart bugs and dead code paths were removed. *(A good area to spot-check while testing: run a few tools that produce charts — POS/verb/adverb analyses, sentiment, parser visualizations — and confirm the Excel charts still open correctly.)*

## v1.6.2
- **Under-the-hood modernization of every tool.** All ~50 GUIs had their **RUN** button rewired to a simpler, more reliable pattern. Nothing changes in how you use the tools — but it removes a long-standing source of bugs and makes future fixes safer.
- **CoNLL Table Analyzer:** you can now run the **Basic and Advanced analyses together** in a single pass, instead of one at a time.
- **GIS distances:** fixed a crash in the **"distance from a baseline location"** mode when the corpus contained places that couldn't be geocoded — those are now skipped cleanly.
- Release-page and housekeeping improvements (dated release titles, a clearer "What's new" section).

## v1.6.1
- **Geographic distances (GIS) tool fully overhauled.** It now works directly on a geocoded corpus and offers three analyses on the same file:
  - distances between **all pairs** of places — within each document, across the whole corpus, or both;
  - distances **from a chosen location** (e.g., how far each place is from New York);
  - **movement** distances between successive places in a story (how far characters travel).
  Results open as readable distribution charts and are saved to their own subfolder.
- **Clearer bar charts across the Suite.** When a chart would show a wall of individual numeric values (distances, sentence lengths, scores…), the values are now grouped into readable ranges/classes.
- **Friendlier file selection.** Picking an input lists the relevant files found for your corpus, with buttons to open a file, remove empty leftover files, or browse — starting in the right folder.
- **Housekeeping.** Removed obsolete one-off scripts and fixed several long-standing bugs (chart generation, coordinate handling, Windows file-name length limits).
