## 📥 What you need to do

1. **Download** the installer for your computer from the **Assets** below:
   - **Windows** → `NLP-Suite-windows-x64.zip`
   - **Mac (Apple Silicon)** → `NLP-Suite-mac-arm64.zip`
2. **Unzip** it, open the unzipped folder, and run **NLP Suite** (Windows) or the **NLP Suite** launcher (Mac). No separate Python install is needed — a portable Python is bundled. See the **getting-started guide** inside the folder if it's your first time.
3. **Mac only:** if macOS blocks the app ("unidentified developer"), right-click the launcher → **Open** (or follow the guide in the folder).
4. **Already have an older version?** Just download this one — there's nothing to uninstall, and your data folders are untouched.
