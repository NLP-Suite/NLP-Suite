### NLP Suite  ![GitHub release (latest by date)](https://img.shields.io/github/v/release/NLP-Suite/NLP-Suite?color=Green&label=Latest%20Version)  

**A freeware, open-source package for Natural Language Processing and visualization**

The NLP Suite provides humanists and social scientists a wide range of computational tools for the analysis and visualization of text data, with no programming required. Our target user is someone with little-to-no NLP expertise.

## Get Started

**[Download and install the NLP Suite](https://github.com/NLP-Suite/NLP-Suite/wiki/Installation-of-the-NLP-Suite)**: download a zip, extract, and double-click. No Python, Anaconda, or Java installation needed.

Available for:
- **Windows** 10/11 (64-bit)
- **macOS** (Apple Silicon: M1/M2/M3/M4/M5)

## What Can It Do?

The NLP Suite offers 50+ GUIs covering:

- **Text analysis:** tokenization, lemmatization, POS tagging, named entity recognition, dependency parsing, coreference resolution, SVO (Subject-Verb-Object) extraction
- **Sentiment & emotion analysis:** BERT, Stanza, VADER, SentiWordNet, ANEW, hedonometer, NRC emotion wheel (with Plutchik visualization)
- **Topic modeling:** BERTopic, Gensim LDA, MALLET
- **Word embeddings:** BERT, Gensim Word2Vec
- **Knowledge graphs:** WordNet aggregation, DBpedia, YAGO
- **Data visualization:** geographic maps (Google Earth, Folium), network graphs (Gephi, vis.js), word clouds, Sankey charts, sunburst charts, boxplots, treemaps, heatmaps, timelines, and more
- **Corpus tools:** n-grams, co-occurrences, text readability, style analysis
- **File handling & pre-processing:** file conversion (PDF/DOCX/RTF to TXT), file merging/splitting, spell checking, filename standardization, file searching, duplicate detection, encoding validation
- **Style analysis & corpus statistics:** sentence complexity (Yngve, Frazier, subordination ratio, dependency distance), lexical diversity (TTR, MTLD, vocd-D), readability scores (Flesch, Gunning Fog, Coleman-Liau), character emotion arcs, entity timelines, frequency distributions, word type/token ratio

## Key Features

- **No programming needed:** everything is accessed through graphical user interfaces with ? help buttons and hover-over tooltips
- **Self-contained:** the standalone build bundles Python, a Java runtime, Stanza, spaCy, NLTK, the BERT libraries and 50+ other packages. Language models (Stanza, spaCy, BERT) download the first time a tool needs them
- **150+ TIPS files:** extensive documentation accessible from every GUI
- **Sample data included:** start testing immediately on first launch
