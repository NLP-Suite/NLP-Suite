======================================================
  NLP Suite — Getting Started
======================================================

WINDOWS
-------
1. Extract the zip file to any folder (e.g. Desktop).
2. Open the extracted folder and double-click NLP_Suite.exe.
3. If Windows shows "Windows protected your PC" (SmartScreen):
   Primary method:
   - Right-click NLP_Suite.exe → Properties
   - Click "Unlock" (bottom right) → OK/Apply

   Alternative method:
   - Click "More info" → Click "Run anyway"

   This only happens the first time.

macOS (Apple Silicon)
---------------------
1. Extract the zip file (double-click it in Finder).
2. Open the extracted folder and double-click
   "Launch NLP Suite (Mac).command".
   Do NOT double-click the "NLP_Suite" file directly — the
   .command launcher clears the macOS quarantine first, then
   starts the suite. Running NLP_Suite directly fails with a
   "code signature ... not valid" / "library load disallowed
   by system policy" error.
3. The first time, macOS may block the launcher with
   "cannot be opened because it is from an unidentified
   developer." This is normal.
4. To allow it (first run only):
   a. Right-click (or Control-click) "Launch NLP Suite (Mac).command"
      in Finder
   b. Choose "Open"
   c. Click "Open" in the confirmation dialog
   After that, a normal double-click works.

   Alternative: Open System Settings > Privacy & Security,
   scroll down to the message about the blocked launcher, and
   click "Open Anyway".

FIRST RUN
---------
On the very first launch, NLP Suite creates two default
configuration files so you can start testing right away:

  - Input folder  : lib/sampleData/newspaperArticles
  - Output folder : ~/Documents/NLP_output (your Documents folder)
  - NLP package   : Stanza
  - Language       : English

You can change these at any time via the I/O Configuration
options at the top of the main window.
