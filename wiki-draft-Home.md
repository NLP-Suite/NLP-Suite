# NLP Suite

**A freeware, open-source package for Natural Language Processing and visualization**

The NLP Suite provides humanists and social scientists a wide range of computational tools for the analysis and visualization of text data — no programming required. Our target user is someone with little-to-no NLP expertise.

## Get Started

**[Download and install the NLP Suite](https://github.com/NLP-Suite/NLP-Suite/wiki/Install-the-NLP-Suite)** — download a zip, extract, and double-click. No Python, Anaconda, or Java installation needed.

Available for:
- **Windows** 10/11 (64-bit)
- **macOS** (Apple Silicon — M1/M2/M3/M4/M5)

## What Can It Do?

The NLP Suite offers 50+ GUIs covering:

- **Text analysis** — tokenization, lemmatization, POS tagging, named entity recognition, dependency parsing, coreference resolution, SVO extraction
- **Sentiment & emotion analysis** — BERT, Stanza, VADER, SentiWordNet, ANEW, hedonometer, NRC emotion wheel (with Plutchik visualization)
- **Topic modeling** — Gensim LDA, MALLET
- **Word embeddings** — BERT, Gensim Word2Vec
- **Knowledge graphs** — WordNet aggregation, DBpedia, YAGO
- **Data visualization** — geographic maps (Google Earth, Folium), network graphs (Gephi, vis.js), word clouds, Sankey charts, sunburst charts, boxplots, treemaps, heatmaps, timelines, and more
- **Corpus tools** — n-grams, co-occurrences, text readability, style analysis

## Key Features

- **No programming needed** — everything is accessed through graphical user interfaces with ? help buttons and hover-over tooltips
- **Self-contained** — the standalone build bundles Python, Stanza, spaCy, NLTK, WordNet, BERT, and 50+ other packages
- **150+ TIPS files** — extensive documentation accessible from every GUI
- **Sample data included** — start testing immediately on first launch
